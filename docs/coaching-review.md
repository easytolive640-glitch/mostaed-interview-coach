# Coach credibility and human review

Run docs/coaching-credentials.sql after the base coaching migration. CVs use the private coach-cvs bucket, with a 1 MB PDF limit and restrictive policies denying direct anon/authenticated access. The server authenticates every upload and download, allows CV downloads only to the applicant or an explicitly configured verified administrator, and generates 60-second download links. Public coach responses include LinkedIn, never CV paths or documents.

Set COACHING_ADMIN_EMAILS to the verified owner email(s), comma-separated, server-only. Administrator eligibility uses the verified Supabase user email, never client metadata. Admin review is shown on coaching.html after sign-in and refreshing My sessions. Review applications manually. Confirm the LinkedIn and CV review and agreed coaching/payout terms, then assign a usable managed Zoom host email or ID before approval. Approval is a human action, not an AI eligibility decision. Review author and timestamp are stored. Pause removes a profile from the public directory.

New applicants must submit LinkedIn, a PDF CV and publication consent. Existing pending/paused applicants can add or replace their credentials in the coach dashboard. Approved profiles need support review for credential changes. PDF signature/size checks are provided; no malware scanning or independent qualification verification is implemented. Never claim uploaded documents alone certify a coach.
